# 02 · Rúbrica de ilustración

Puntúa cada criterio de **1 a 4**:
- **1** No funciona / distrae
- **2** Funciona a medias, se notan problemas
- **3** Funciona bien
- **4** Destaca, refuerza la intención

| # | Criterio | Pregunta clave | Prueba rápida en CSP | Nota |
|---|---|---|---|---|
| 1 | **Idea / narrativa** | ¿Se entiende qué pasa o qué se quiere transmitir en 3 segundos? | Mira la miniatura en el *Navegador* | |
| 2 | **Composición** | ¿El ojo va al punto focal? ¿Hay recorrido visual y equilibrio? | Reglas de composición / rejilla, volteo horizontal | |
| 3 | **Valores** | ¿Se lee en escala de grises? ¿Hay jerarquía clara de claro/oscuro? | Capa de corrección *Mapa de degradado* o capa de color en modo *Color* gris | |
| 4 | **Dibujo / construcción** | Proporciones, perspectiva, volumen, anatomía | Volteo horizontal, reglas de perspectiva, modelo 3D | |
| 5 | **Línea** | ¿Varía el grosor? ¿Es limpia y con intención? | Zoom 100% y zoom alejado | |
| 6 | **Color** | ¿La paleta es coherente y apoya el ambiente? ¿Temperatura de luz/sombra? | Paleta *Rueda de color*, capa en modo *Saturación* | |
| 7 | **Luz y sombra** | ¿La fuente de luz es consistente? ¿Formas bien definidas? | Ocultar capa de luz y comparar | |
| 8 | **Bordes y detalle** | ¿Hay variedad de bordes (duros/suaves/perdidos)? ¿El detalle está donde está el foco? | Desenfoque para ver masas | |
| 9 | **Acabado técnico** | Resolución, limpieza, sin huecos, exportación correcta | Ver [05 · Clip Studio](05-clip-studio.md) | |

**Total: ___ / 36**

## Errores frecuentes a revisar
- Todo con el mismo nivel de detalle → no hay foco.
- Valores medios por todas partes → imagen “plana”.
- Sombras simplemente “más oscuras” en vez de cambiar tono/temperatura.
- Tangentes (dos bordes que se tocan justo) y elementos cortados en zonas incómodas.
- Saturación máxima por todas partes.
- Personaje centrado sin motivo y fondo sin relación con él.
