# 03 · Rúbrica de animación

Escala **1 a 4** (igual que ilustración). Revisa siempre la animación **en bucle**, a velocidad real y fotograma a fotograma.

| # | Criterio | Pregunta clave | Nota |
|---|---|---|---|
| 1 | **Claridad de la acción** | ¿Se entiende la acción solo con las poses clave? | |
| 2 | **Poses / staging** | ¿Las poses son legibles en silueta? ¿La cámara/encuadre ayuda? | |
| 3 | **Timing** | ¿La duración transmite peso, intención y emoción? | |
| 4 | **Espaciado** (ease in/out) | ¿Acelera y frena de forma creíble? | |
| 5 | **Arcos** | ¿Las partes se mueven en arcos naturales y no en zigzag? | |
| 6 | **Squash & stretch** | ¿Se conserva el volumen? ¿El grado encaja con el estilo? | |
| 7 | **Anticipación** | ¿Hay preparación antes de las acciones fuertes? | |
| 8 | **Follow-through / overlap** | Pelo, ropa, cola: ¿siguen moviéndose y se retrasan? | |
| 9 | **Peso** | ¿Se siente la gravedad y la masa? | |
| 10 | **Consistencia del dibujo** | ¿El personaje mantiene volumen y proporciones (no “hierve” sin querer)? | |
| 11 | **Acting / apelación** | ¿Transmite personalidad o emoción? | |
| 12 | **Técnica** | FPS correctos, bucle sin saltos, limpieza de línea, exportación | |

**Total: ___ / 48**

## Cómo revisar en Clip Studio Paint
- **Papel cebolla** (*Animación → Mostrar celdas de animación → Habilitar papel cebolla*): revisa espaciado y arcos.
- Dibuja los **arcos** en una capa aparte encima, siguiendo un punto (nariz, mano) fotograma a fotograma.
- **Mesa de luz** (paleta *Mesa de luz de animación*): para intermedios.
- Ajusta **duración de celdas** directamente en la *Línea de tiempo* para probar timing sin redibujar.
- Reproduce a la **velocidad final** (12 o 24 fps; animar “en 2s” a 24 fps = 12 dibujos/s).

## Ejercicios de base recomendados (en orden)
1. Pelota rebotando (timing, espaciado, squash & stretch)
2. Pelota con cola (overlap)
3. Péndulo / bandera (follow-through)
4. Saco de harina saltando (peso, anticipación, acting simple)
5. Ciclo de caminata (arcos, peso, ritmo)
6. Ciclo de carrera
7. Toma de peso: levantar un objeto pesado
8. Acting corto con una frase de audio (2–4 s)

## Para pedir crítica a Claude
Exporta 3–6 fotogramas clave como imágenes (o una hoja de contacto con todos los fotogramas) e indica los FPS y la duración de cada celda:
> “Estos son los fotogramas de un ___ a ___ fps. Duraciones: ___. Evalúalo con la rúbrica de animación y dime dónde falla el timing/espaciado y qué fotogramas cambiar.”
