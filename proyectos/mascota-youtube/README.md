## De qué trata
Mascota para un canal de YouTube: un **perro luchador** con estilo mexicano.

## Requisitos del diseño
1. **Icónico**: se reconoce en pequeño (avatar de 48 px, miniaturas).
2. **Fácil de animar**: pocas piezas, trazos sencillos, colores planos.
3. **Estilo gráfico mexicano**: lucha libre, lotería, papel picado, cartel popular (ver [moodboard](referencias/moodboard.png)).
